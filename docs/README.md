# Treko — Interactive Mockup

Λειτουργικό mockup της εφαρμογής **Treko** (προτάσεις εκδρομών στην Ελλάδα, πρόγνωση
καιρού, ομαδικές εξορμήσεις), φτιαγμένο από το Figma design.

**Χωρίς pnpm, χωρίς npm, χωρίς build.** Σκέτα HTML / CSS / JavaScript. Ανοίγει
κατευθείαν σε κάθε browser και σε κάθε μέγεθος οθόνης — κινητό, tablet, desktop.

---

## 1. Πώς το ανοίγεις

Υπάρχουν δύο εκδοχές μέσα στον φάκελο — ίδια εφαρμογή, διαφορετική χρήση.

### Α) `treko.html` — ένα και μόνο αρχείο

Όλα (CSS, JavaScript, φωτογραφίες) είναι ενσωματωμένα μέσα του. **Διπλό κλικ και
ανοίγει** — σε Windows, Mac, κινητό, οπουδήποτε. Δεν χρειάζεται server, internet
ούτε τίποτα εγκατεστημένο. Στείλ' το με email ή WeTransfer και ανοίγει το ίδιο.

Χρήσιμο για παρουσίαση. Προσοχή: είναι **στιγμιότυπο** — αν αλλάξεις κάτι στα
αρχεία του φακέλου, το `treko.html` δεν ενημερώνεται μόνο του.

### Β) Ο φάκελος — για online link και για αλλαγές

Αυτή είναι η έκδοση που επεξεργάζεσαι (δες §3).

#### ⚠ Για να βγάλεις link στο GitHub

Δύο πράγματα που μπερδεύουν:

1. **Link σε αρχείο `.html` μέσα στο GitHub δείχνει τον κώδικα, όχι τη σελίδα.**
   Το `github.com/.../blob/main/index.html` θα σου δείξει HTML σε γκρι φόντο.
   Για να «τρέξει» η σελίδα χρειάζεται **GitHub Pages**.

2. **Το GitHub Pages σε δωρεάν λογαριασμό θέλει το repo να είναι public.**
   Σε private repo το Pages απαιτεί GitHub Pro (~4$/μήνα).

Βήματα όταν το repo είναι public:

1. Ανέβασε αυτόν τον φάκελο ως `docs/`.
2. **Settings → Pages**.
3. **Source:** `Deploy from a branch` · **Branch:** `main` · **Folder:** `/docs`.
4. **Save** και περίμενε 1–2 λεπτά.

Η διεύθυνση θα είναι: `https://<username>.github.io/<repo>/`

> Αν το repo πρέπει να μείνει private, εναλλακτικές χωρίς χρέωση:
> ανέβασε τον φάκελο σε **Netlify Drop** (netlify.com/drop — σύρε τον φάκελο, παίρνεις
> link σε 10 δευτερόλεπτα) ή **Cloudflare Pages**. Και τα δύο σερβίρουν στατικά
> αρχεία δωρεάν χωρίς build.

## 3. Πώς κάνεις αλλαγές μέσα από το GitHub

Δεν χρειάζεσαι τίποτα εγκατεστημένο. Στο GitHub:

1. Άνοιξε το αρχείο.
2. Πάτα το **μολυβάκι** (Edit this file).
3. Κάνε την αλλαγή → **Commit changes**.
4. Σε ~1 λεπτό ανανεώνεται η σελίδα.

### Αλλαγή κειμένων ή προορισμών → `js/data.js`

Κάθε προορισμός είναι ένα μπλοκ. Αντιγράφεις ένα και το αλλάζεις:

```js
{
  id: "vikos",                       // μοναδικό, χωρίς κενά
  name: "Φαράγγι του Βίκου",
  area: "Ζαγόρι, Ήπειρος",
  region: "Ήπειρος",                 // εμφανίζεται στα φίλτρα
  activity: "Πεζοπορία",             // Πεζοπορία | Παραλία | Ποδηλασία | Πολιτιστικά
  difficulty: "Μέτρια",              // Εύκολη | Μέτρια | Δύσκολη
  duration: "Ολόκληρη μέρα",         // Λίγες ώρες | Μισή μέρα | Ολόκληρη μέρα
  hours: 6,
  lat: 39.95, lon: 20.73,            // για την πρόγνωση καιρού
  image: "images/vikos-gorge.jpg",
  ...
}
```

### Αλλαγή φωτογραφίας

Ανέβασε τη νέα φωτογραφία στον φάκελο `images/` (Add file → Upload files) και
γράψε το όνομά της στο πεδίο `image` του προορισμού.

### Αλλαγή χρωμάτων → `styles.css`, πρώτες γραμμές

```css
:root {
  --forest: #04382a;   /* σκούρο πράσινο */
  --cream:  #f7efc8;   /* κρεμ */
  --paper:  #faf5dc;   /* φόντο σελίδας */
  --card:   #fffdf2;   /* κάρτες */
  ...
}
```

Αλλάζεις έναν κωδικό χρώματος εδώ και αλλάζει παντού.

## 5. Σημειώσεις

- **Καιρός:** έρχεται ζωντανά από το [Open-Meteo](https://open-meteo.com) (χωρίς
  κλειδί, δωρεάν). Αν δεν υπάρχει internet, η εφαρμογή δουλεύει κανονικά και απλώς
  δεν δείχνει πρόγνωση.
- **Δεδομένα:** λογαριασμοί, αγαπημένα και εκδρομές μένουν **μόνο στη συσκευή**
  (localStorage). Δεν φεύγει τίποτα σε server. Είναι mockup — μην βάλεις αληθινό κωδικό.
- Κάθε ανανέωση της σελίδας ξεκινά από την οθόνη καλωσορίσματος, για να φαίνεται
  ολόκληρη η ροή σε κάθε παρουσίαση.
- Οι ημερομηνίες των demo εκδρομών υπολογίζονται από τη σημερινή μέρα, οπότε είναι
  πάντα «επερχόμενες».
