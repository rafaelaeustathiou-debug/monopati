# Treko

Λειτουργικό mockup της εφαρμογής **Treko** — προτάσεις εκδρομών στην Ελλάδα,
πρόγνωση καιρού, ομαδικές εξορμήσεις.

Σκέτα HTML / CSS / JavaScript. **Χωρίς pnpm, χωρίς npm, χωρίς build.**
Προσαρμόζεται αυτόματα σε κινητό, tablet και desktop.

## Live

Ενεργοποίησε GitHub Pages: **Settings → Pages → Source: Deploy from a branch →
Branch: `treko` → Folder: `/docs`**.

## Περιεχόμενα

- `docs/index.html` — η εφαρμογή (η έκδοση που επεξεργάζεσαι)
- `docs/treko.html` — ΕΝΑ αρχείο με όλα μέσα· διπλό κλικ και ανοίγει, και χωρίς internet
- `docs/js/`, `docs/styles.css`, `docs/images/`, `docs/assets/` — ο κώδικας και τα γραφικά
- `docs/.nojekyll` — απαραίτητο για να σερβίρει σωστά το GitHub Pages
