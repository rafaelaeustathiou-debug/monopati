# Treko

**Treko** είναι εφαρμογή που προτείνει εκδρομές στην Ελλάδα, δείχνει την πρόγνωση
του καιρού για κάθε προορισμό και σε βοηθά να οργανώσεις ομαδικές εξορμήσεις.

Πρόκειται για **λειτουργικό mockup** (πρωτότυπο που δουλεύει). Μπορείς να πατήσεις κουμπιά,
να συμπληρώσεις φόρμες και να περιηγηθείς σε όλες τις οθόνες, όπως σε κανονική εφαρμογή.
Ταιριάζει αυτόματα σε κινητό, tablet και υπολογιστή.

---

## Γρήγορο ξεκίνημα: δες την εφαρμογή σε 10 δευτερόλεπτα

1. Άνοιξε τον φάκελο **`docs/`**.
2. Κάνε **διπλό κλικ στο `treko.html`**.

Ανοίγει στον browser σου (Chrome, Safari, Edge, Firefox). **Δεν χρειάζεται να εγκαταστήσεις
τίποτα** και δουλεύει και χωρίς internet. Τη μόνη διαφορά χωρίς internet θα τη δεις
στην πρόγνωση του καιρού, που δεν θα εμφανίζεται.

> Αν έλαβες το project από το GitHub: πάτα το πράσινο κουμπί **Code → Download ZIP**,
> αποσυμπίεσε το αρχείο και ακολούθησε τα παραπάνω βήματα.

## Τι μπορείς να δοκιμάσεις

| Οθόνη | Τι κάνει |
|---|---|
| Καλωσόρισμα | Εγγραφή, σύνδεση ή συνέχεια ως επισκέπτης |
| Εγγραφή / Σύνδεση | Ελέγχει τα πεδία και δείχνει μηνύματα λάθους |
| Ερωτηματολόγιο | 4 ερωτήσεις για τις προτιμήσεις σου, που αλλάζουν τις προτάσεις |
| Αρχική | Προτεινόμενοι προορισμοί, φίλτρα δραστηριότητας, ειδοποιήσεις |
| Αναζήτηση | Αναζήτηση την ώρα που πληκτρολογείς (με ή χωρίς τόνους) και φίλτρα |
| Προορισμός | Στοιχεία διαδρομής, καιρός 7 ημερών, ομαδικές εκδρομές |
| Εκδρομές | Επερχόμενες και δικές μου, συμμετοχή ή αποχώρηση |
| Νέα εκδρομή | Δημιουργία εκδρομής με πρόγνωση καιρού για την ημερομηνία |
| Ομαδική συνομιλία | Μηνύματα με την ομάδα της εκδρομής |
| Αγαπημένα | Αποθήκευση προορισμών που σου αρέσουν |
| Προφίλ | Στατιστικά, προτιμήσεις, επαναφορά των δοκιμαστικών δεδομένων |

**Καλό να ξέρεις:**
- Ό,τι καταχωρείς (λογαριασμός, αγαπημένα, εκδρομές) μένει **μόνο στη δική σου συσκευή**
  και δεν στέλνεται πουθενά. Επειδή είναι πρωτότυπο, **μη βάλεις πραγματικό κωδικό**.
- Κάθε φορά που ανανεώνεις τη σελίδα, ξεκινάς ξανά από την οθόνη καλωσορίσματος.
- Ο καιρός έρχεται ζωντανά από την υπηρεσία [Open-Meteo](https://open-meteo.com).

## Για όσους θέλουν να τη δημοσιεύσουν online

Για να έχεις ένα link που ανοίγει σε όποιον το στείλεις, χρησιμοποίησε δωρεάν
στατική φιλοξενία. Δεν χρειάζεται build.

**Επιλογή 1: Netlify Drop (η πιο εύκολη)**
Πήγαινε στο [app.netlify.com/drop](https://app.netlify.com/drop) και σύρε μέσα τον φάκελο
`docs/`. Σε λίγα δευτερόλεπτα έχεις link.

**Επιλογή 2: GitHub Pages**
Στο repository: **Settings → Pages → Source: Deploy from a branch → Branch: `main` →
Folder: `/docs` → Save**. Σε 1–2 λεπτά η εφαρμογή ανοίγει στο
`https://<username>.github.io/<repo>/`.
Σε δωρεάν λογαριασμό GitHub το repository πρέπει να είναι **public**.

> Ένα link σε αρχείο `.html` μέσα στο github.com δείχνει τον **κώδικα** και όχι τη σελίδα.
> Για να ανοίξει η σελίδα κανονικά χρειάζεται μία από τις παραπάνω επιλογές.

## Για προγραμματιστές: εκτέλεση τοπικά

Ο κώδικας της εφαρμογής είναι απλό HTML, CSS και JavaScript στον φάκελο `docs/`.
Ένας τοπικός server δίνει αυτόματη ανανέωση όταν αλλάζεις κάτι. Η εφαρμογή ανοίγει στο
**http://localhost:8443**.

**Με Docker:**
```sh
docker compose up --build
```

**Με Node.js (έκδοση 20 ή νεότερη):**
```sh
corepack enable
pnpm install
pnpm dev
```

**Με GitHub Codespaces:** πάτα **Code → Codespaces → Create codespace**. Ο server
ξεκινά αυτόματα και το preview ανοίγει από το tab **Ports** (θύρα 8443).

## Δομή αρχείων

```
docs/                ← η εφαρμογή
├── treko.html       ← ΕΝΑ αρχείο με όλα μέσα (διπλό κλικ και ανοίγει)
├── index.html       ← η κανονική έκδοση, που φορτώνει τα παρακάτω αρχεία
├── styles.css       ← όλη η εμφάνιση (χρώματα και γραμματοσειρές στην αρχή)
├── js/
│   ├── data.js      ← το περιεχόμενο: προορισμοί, κείμενα, δοκιμαστικές εκδρομές
│   ├── screens.js   ← οι οθόνες της εφαρμογής
│   ├── app.js       ← συνδέει τα πάντα: κλικ, φόρμες, πλοήγηση
│   ├── store.js     ← αποθήκευση δεδομένων στη συσκευή
│   ├── weather.js   ← πρόγνωση καιρού
│   ├── lib.js       ← βοηθητικές λειτουργίες και αλγόριθμος προτάσεων
│   └── icons.js     ← εικονίδια
├── images/          ← φωτογραφίες προορισμών
└── assets/          ← λογότυπο και γραφικά
```

Το `treko.html` είναι **στιγμιότυπο**. Αν αλλάξεις αρχεία στον φάκελο, δεν ενημερώνεται
μόνο του.

Οδηγίες για αλλαγές (κείμενα, προορισμοί, φωτογραφίες, χρώματα) υπάρχουν στο
[docs/README.md](docs/README.md).
